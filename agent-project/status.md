# 当前状态

## 当前工作单元

`codex/fix-evidence-report-chain` 分支上的 v1.2 确定性修复已经完成，可以进入不承诺准确率的免费或低价小范围投放。当前版本已经把“关系本身如何”与“什么影响判断和投入”分开计分，并补齐了答案证据、阶段适配、报告行动链、隐私分享和本地续答。尚未经过真实用户验证，因此“被说中感、付费价值、点赞/评论/分享意愿”仍是待投放检验的产品假设。

## 当前状态

- 题库仍为 28 题；按阶段展示 25 道 ongoing、16 道 ended。题目只做了高风险语义和选项修复，没有整体推翻或大批量改写。
- 关系层与五类影响来源已在题目适用性和分值上解耦；纯来源题不能改变关系结论，纯关系题不能改变来源结论。
- ended 可以得到“过去曾明显滋养”的关系叙事，但不会被判为当前“双向生长”；ended 的洞察、观察信号和行动均采用回顾场景，不要求联系对方。
- “现实约束”与“害怕失去”分开呈现；来源充分但五类都不突出时显示 `not_prominent`，不再误报为信息不足。
- 报告现在展示所选答案证据、主次来源、组合洞察证据、关系强项和最低项，并形成“证据—解释—下一步”链路。
- 正式页面默认隐藏测试预设和答案导入导出，只有 `?debug=1` 显示；作答过程自动保存在本机，完成或重新开始后清除。
- 分享文字只复制结果标题和一句可公开表达，不包含用户选择的具体答案；页面保留非诊断、非决策替代和安全求助边界。

## 阻塞或风险

- 没有真实用户样本，不能声称已经证明“很准”、值得付费或会带来点赞/评论/分享；当前只能确认规则自洽、证据可追溯、页面可完成。
- 阈值仍属于产品规则而非心理测量常模；尤其弱来源、主次接近和边界用户，需要根据首批匿名结果与逐句反馈校准。
- 当前项目是可本地运行的单页 MVP，尚未包含正式托管、支付、订单交付或经营分析闭环；上线平台选择属于下一工作单元。

2. 至少收集完成率、结果页到达率、复制分享点击、评论原话，以及用户标注的“最像/最不像/新增理解”句子。
