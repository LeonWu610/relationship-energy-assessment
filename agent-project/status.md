## 已确认的内容失败模式

- 主结论没有稳定直接说“偏滋养/偏消耗/并存”；用户真实结果应是“整体偏滋养，同时夹杂少量消耗”。
- “有现实支撑”“一处需要观察”“没有某种感受突出”等表达可能含糊、虚假精确或像没有结果。
- 文案经常把题目选项换句话复述，缺少付费用户期待的新增洞察。
- 低来源只能作为次级解释，不能抢占主结论。
- “保留自己”“符合你的需要”等话太抽象；必须落到真实想法、朋友兴趣、生活节奏或具体行动。
- 维度 `repair` 的目标用户文案是“产生矛盾后能否一起解决”；主 JSON 当前仍为“闹矛盾后能否一起解决”，随结果内容模型一起修复，避免在本轮文档审查中提前改业务事实源。
